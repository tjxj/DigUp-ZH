# DigUp-ZH 0.1.0 验证记录

验证环境：Apple M4、16 GB 内存、macOS 27.0、Swift 6.2.3。最低部署目标为 macOS 14；未在所有受支持系统和机型上逐一实测。以下样例验证功能，不代表通用准确率或速度榜单。

## 自动测试

- 基础测试共 106 项：103 项执行通过；3 项需要真实模型的检查在普通运行时跳过。
- 随后启用真实模型，文字语义、图片语义、重复输入一致性和固定参考结果全部通过（4 项，包含重复执行的模型声明检查）。
- 中文检查涵盖无空格输入、简繁体、全半角、文件名与改名、中英混排及编号、中文跨行高亮、中文长文与长 PDF 末尾、旧关键词索引迁移、OCR。
- 新增小资料库检查：只有一个文件时仍可按意思找到它；无关描述和不存在的编号不因兜底规则被强行返回。
- 路径别名检查：临时目录的两种系统路径写法可以重复整理，索引范围与保留操作一致。

复现：

```sh
scripts/build-llama.sh
bash scripts/test.sh
DIGUP_MODELS="$PWD/.models" DIGUP_REAL_MODEL_TESTS=1 \
  bash scripts/test.sh --filter 'QwenRuntimeTests|ReferenceVectorTests'
```

## 安装与离线

- 应用内置指定的 Q4_K_M 文件及配套视觉文件，打包前按固定 SHA-256 校验。
- 在禁止网络的测试环境中完成首次引导、13 个文件的整理、中文查询及预览；模型直接读取应用内部文件。
- 实际绘制并检查欢迎页、设置页、菜单图标、搜索面板、PDF 搜索窗口及高亮。
- 下载模块使用两份真实完整的临时文件验证：校验后进入就绪、仅通知一次；目标无法写入时明确报错，保留临时文件和原目标，不重复循环。
- 最终 DMG 已通过挂载和完整应用签名结构检查，使用 APFS 避免打包时产生影响校验的 Finder 附加信息。安装包约 1.73 GB。
- 已从最终只读 DMG 直接启动应用，在禁止网络的环境中完成中文查询，并再次确认模型文件校验值及随包致谢与源码一致。

## 边界

- 本次桌面处于锁屏状态，物理点击、真实中文输入法候选窗和全局快捷键的最终人工式复测未完成；离屏流程与绘制检查已完成。代码保留组合输入保护。
- 搜索排序有启发式规则，少量样例通过不保证每个查询准确。小资料库采用保守相似度兜底，阈值并非概率。
- 中文 OCR 会受字体和图片清晰度影响。视频只检索采样画面，不识别对白。
- 本地签名通过应用包结构校验；没有 Apple Developer ID 证书，未经过 Apple 公证。
